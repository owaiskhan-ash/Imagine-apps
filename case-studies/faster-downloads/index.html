Faster Downloads

An Android download manager that can use Wi-Fi and mobile data together for supported downloads.

A download manager for two networks

Faster Downloads is an Android app that can use Wi-Fi and mobile data together to download a file. For compatible HTTP servers it divides a file into ranges and assigns work across the available networks. It also supports magnet links.

Managing downloads

The project documents progress and speed readouts for each network, a download queue, pause and resume, and a foreground progress notification. Downloaded files are stored on the device, and the interface offers day and night themes.

Compatibility matters

The multipath HTTP approach requires a server that supports range requests. The project describes a fallback to a single connection when a server ignores ranges. Network availability, Android device behaviour, data charges and the download source can affect the experience and any speed improvement.
